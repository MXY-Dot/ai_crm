## Agent skills

### Issue tracker

Issues and specs are tracked as local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-role vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain docs layout. See `docs/agents/domain.md`.
### UI components

Use the project's existing Vue UI components (`resources/js/components/ui/*`) for all UI work. Do not add shadcn, shadcn-vue, or another UI kit unless the user explicitly asks for it.
